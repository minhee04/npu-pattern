# Mini NPU Simulator

## 1. 프로젝트 소개
MAC(Multiply-Accumulate) 연산을 이용하여 2차원 패턴을 분류하는 Python 콘솔 프로그램이다.
Cross 필터와 X 필터의 MAC 점수를 비교하여 입력 패턴을 분류한다.

## 2. 실행 환경
- Python 3.8 이상
- json, time 표준 라이브러리 사용
- 외부 라이브러리 미사용

## 3. 파일 구성
- main.py: MAC 연산 및 패턴 분류 프로그램
- data.json: 크기별 필터와 테스트 패턴 데이터
- README.md: 프로젝트 설명 및 결과 리포트

## 4. 실행 방법
프로젝트 폴더에서 다음 명령어를 실행한다.

    python main.py

1. 사용자 입력 모드
2. JSON 테스트 모드
3. 성능 측정
0. 종료

## 5. 주요 구현 내용

### MAC 연산
중첩 반복문으로 두 행렬의 같은 위치에 있는 원소를 곱하고 합산한다.

### 행렬 검증
행과 열의 개수 및 숫자 입력 여부를 검사한다.

### 라벨 정규화
+, Cross, cross는 Cross로 통일한다.
x, X는 X로 통일한다.

### 패턴 분류
두 MAC 점수를 비교한다.
두 점수의 차이가 epsilon(1e-9)보다 작으면 UNDECIDED로 판정한다.

### JSON 처리
패턴 ID에서 행렬 크기를 추출하고 해당 크기의 필터를 선택한다.
입력 행렬의 크기를 검증한 뒤 예상 정답과 실제 결과를 비교한다.

### 성능 측정
각 행렬 크기별 MAC 연산을 100회 반복하고 평균 실행 시간을 측정한다.

## 6. 결과 리포트

### JSON 테스트 결과
전체 테스트 6개 중 PASS 3개, FAIL 3개가 발생했다.
size_5_2, size_13_1, size_25_2는 PASS였다.
size_5_1, size_13_2, size_25_1은 FAIL이었다.

실패 사례는 실제 분류 결과와 예상 정답이 일치하지 않았다.
세 사례 모두 두 MAC 점수의 차이가 epsilon 기준보다 작았다.
부동소수점 연산으로 인해 매우 작은 점수 차이가 발생할 수 있다.
epsilon 비교 정책에 따라 해당 사례는 UNDECIDED로 분류되었다.
라벨 정규화를 통해 +와 Cross, x와 X의 표현 차이를 통일했다.
JSON 데이터의 키와 행렬 크기 불일치도 별도로 검증하도록 구현했다.
제공된 데이터와 판정 정책을 유지했으며 임의로 정답을 변경하지 않았다.

### 성능 측정 결과

| 행렬 크기 | 평균 시간(ms) | 연산량(N²) |
|---|---:|---:|
| 3x3 | 0.000343 | 9 |
| 5x5 | 0.001322 | 25 |
| 13x13 | 0.003897 | 169 |
| 25x25 | 0.012013 | 625 |

행렬 크기가 N x N일 때 각 원소를 한 번씩 계산하므로 연산량은 N²이다.
따라서 MAC 연산의 시간 복잡도는 O(N²)이다.
실행 시간은 컴퓨터 환경에 따라 달라질 수 있다.

## 7. 재현 방법
1. 저장소를 내려받는다.

3. python main.py를 실행한다.
4. JSON 테스트 모드에서 분류 결과를 확인한다.
5. 성능 측정 메뉴에서 크기별 실행 시간을 확인한다.
